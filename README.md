- `[아이콘] 수행 비기・Ⅲ × 2` 형식으로 아이콘·이름·수량을 한 줄에 표시합니다.

- 아이콘 아래에 필요 수량과 한국어 아이템명을 함께 표시합니다.
- 사이트에서 사용하는 강화재료 ID 130종의 아이콘 연결을 확인했습니다.

## v63 수정

- 니키타 전투/피버 스킬의 단계별 지속시간, 피해, 보호막 수치를 한국 클라이언트 `BaseSkillBuff` 연결값으로 교정했습니다.
- 에스텔 전투 스킬의 공속 감소, 공격력 증가, 최대 중첩, 회복 수치를 1~6레벨별로 교정했습니다.
- 알리시스 전투/피버 스킬의 방어력 증가, 부활 회복, 직접 피해, 지속 피해 수치를 1~6레벨별로 교정했습니다.
- `damage_rate=0`인 버프형 스킬을 0% 피해로 잘못 치환하지 않도록 표시 로직을 수정했습니다.

- 만렙풀돌 스탯은 제공 자료에 있는 캐릭터/항목만 반영했습니다.
- 배지 추천은 기존 추천이 있는 경우 기존 표시는 유지하고, GameKee 추천은 비고에 추가했습니다.

- 중국어명/한국어명이 중복 매칭된 항목은 하나로 정리했습니다.
